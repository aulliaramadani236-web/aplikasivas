SEBELUM MULAI

Kenali lebih dekat.

Beberapa hal yang perlu Anda ketahui tentang VAS versi saat ini.

Siapa yang bisa menggunakan VAS?

VAS dirancang untuk pemilik UMKM yang ingin mengelola penjualan, produk, persediaan, pelanggan, dan pencatatan keuangan dalam satu aplikasi.

Bisakah saya mencoba sebelum membuat akun?

Bisa. Buka aplikasi, lalu pilih “Jelajahi data demo” pada halaman masuk untuk mencoba ruang usaha dengan data contoh.

Di mana data usaha saya disimpan?

Versi saat ini menyimpan akun dan data secara lokal di browser perangkat Anda. Data belum tersinkron antarperangkat. Unduh cadangan melalui Pengaturan secara berkala karena menghapus data browser akan menghapus catatan Anda.

Apakah laporan dapat diunduh?

Anda dapat mengekspor catatan ke CSV dan mencetak laporan atau menyimpannya sebagai PDF melalui browser. Cadangan data JSON tersedia pada halaman Pengaturan.
